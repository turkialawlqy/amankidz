# أمان كيدز TV — نسخة LG webOS

نسخة متكاملة لنظام **LG webOS TV** مبنية باستخدام **React 18 + Vite + TypeScript + Tailwind CSS** ومهيأة خصيصاً للتنقل بريموت شاشات LG (D-Pad + Magic Remote).

---

## 🌟 الميزات المضمنة في نسخة webOS:

1. **الربط التلقائي والآمن (Pairing Screen):**
   - تسجيل مجهول للجهاز في Supabase.
   - توليد كود ربط مكون من 6 أرقام مع عداد زمني (10 دقائق) وشريط تقدم.
   - انتقال فوري للشاشة الرئيسية بمجرد إدخال الكود من موقع الأهل (`tv.nafasoud.com`).

2. **التنقل بالريموت (D-Pad & Magic Remote):**
   - محرك تنقل جغرافي (Spatial Navigation) بالأسهم والـ OK.
   - دعم زر الرجوع الخاص بشاشات LG (`keyCode: 461`).
   - دعم مؤشر الفأرة الذكي (Magic Remote Pointer).

3. **الواجهة والشاشات:**
   - تصميم متطابق مع هوية التطبيق وثيم "شاهد" المسطح باللون الكحلي والفيروزي والخط العربي (تجوال).
   - بنر رئيسي (Hero Banner) لعرض أحدث الحلقات أو الفيديوهات مع أزرار تشغيل وتفاصيل.
   - رفوف المحتوى الأفقية (الأفلام، المسلسلات، قنوات البث المباشر، محتوى الأهل).
   - نافذة تفاصيل العمل (Details Modal) مع طاقم العمل، الوصف، وقائمة الحلقات.

4. **مشغّل الفيديو (Custom Player):**
   - تشغيل تدفقات HLS والبث المباشر (m3u8) عبر تسريع العتاد.
   - شريط تحكم سينمائي (OSD) يظهر ويختفي تلقائياً.
   - زر عائم "تخطي المقدمة" (Skip Intro) في بداية الحلقة.
   - زر "الحلقة التالية" قرب نهاية الحلقة.
   - تقديم وتأخير 10 ثوان بالأسهم.

5. **الملفات الشخصية للأطفال (Child Profiles):**
   - إمكانية التبديل بين الأطفال.
   - دعم قفل الملف الشخصي برمز سري PIN مع لوحة أرقام متوافقة مع الريموت.

6. **إذن الخروج وأوامر الأهل (Parental Control):**
   - قفل الخروج برمز الأب (Settings PIN).
   - الاستماع اللحظي لأمر قفل الشاشة (Lock TV) وعرض شاشة القفل فوراً.
   - عرض الرسائل الفورية المرسلة من الأهل على شاشة التلفزيون.

## 🚀 أوامر التشغيل والبناء:

### 1. التجربة المحلية في المتصفح:
```bash
cd webos-tv
npm run dev
```

### 2. بناء ملفات الإنتاج (Production Build):
```bash
cd webos-tv
npm run build
```
تُنتج هذه الخطوة مجلد `dist/` جاهزاً لحزمة webOS مع كافة الملفات و `appinfo.json`.

## 📺 التثبيت على شاشة LG (Developer Mode):

1. **تفعيل وضع المطورين على شاشة LG:**
   - من متجر شاشة LG (LG Content Store)، ابحث عن تطبيق **Developer Mode** وثبّته.
   - افتح التطبيق وسجّل دخولك بحساب LG Developer، ثم فعّل **Dev Mode Status** و **Key Server**.

2. **تثبيت webOS TV CLI على جهازك (مرة واحدة):**
   - نزّل أدوات webOS TV CLI من موقع LG Developer:
     `npm install -g @webos-tools/cli`

3. **ربط الشاشة بالكمبيوتر:**
   ```bash
   ares-setup-device
   ```
   (اختر add، وأدخل عنوان IP الشاشة والمنفذ الظاهر في تطبيق Developer Mode بالشاشة).

4. **حزم التطبيق بصيغة IPK:**
   ```bash
   ares-package dist
   ```
   سيتولد ملف: `com.turkialawlqy.aman_3.2.0_all.ipk`.

5. **تثبيت التطبيق على الشاشة:**
   ```bash
   ares-install com.turkialawlqy.aman_3.2.0_all.ipk
   ```
